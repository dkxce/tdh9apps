# Смена boot-логотипа TD-H9 по Bluetooth

`td9_logo.py` читает и пишет **boot-логотип** рации TD-H9 на resource flash
по Bluetooth через сервис ресурсного flash (S1 read / S2 write).

## Формат логотипа

| Параметр | Значение |
|---|---|
| Адрес на чипе | `0xA00000` |
| Размер | 160 × 128 px |
| Формат | сырой RGB565 big-endian (без заголовка) |
| Размер байт | 40 960 Б (10 секторов по 4 КиБ) |

## Команды

Все примеры через `poetry run`.

### Прочитать текущий логотип / бэкап
```
poetry run python td9_logo.py read [--output имя_файла]
```
- Сохраняет текущий логотип на диск как `td9-logo.bin` (или `--output`).
- Полезно **перед записью** — сохранить оригинал, чтобы вернуть.

### Записать новый логотип
```
poetry run python td9_logo.py write картинка.png [--dither]
poetry run python td9_logo.py write лого.bin
```

| Аргумент | Наимен. | Что делает |
|---|---|---|
| `картинка.png/jpg` | — | Pillow: ресайз до 160×128 (LANCZOS) → RGB565 big-endian |
| `--dither` | флаг | Floyd–Steinberg дизеринг градиентов (меньше полос) |
| `лого.bin` | — | готовый сырой RGB565 160×128 (40 960 Б), используется как есть |

Перед записью скрипт:
1. проверяет write service (S2, версия 2);
2. **читает текущий логотип**, чтобы спланировать сектора к перезаписи;
3. стирает и программирует только изменившиеся сектора;
4. читает обратно и сверяет.

## Замечания

- **Требуется прошивка с write service** (H9 Toolbox / Custom). Без неё (stock S1)
  запись недоступна — пишет об этом.
- `--backup` определён в интерфейсе, но автоматическое сохранение резервной
  копии при `write` **не реализовано**. Для бэкапа сделайте `read` вручную:
  ```
  poetry run python td9_logo.py read -o my-original-logo.bin
  ```
- Установка картинок пакетом — см. `td9_kpi.py` (DKXCEPIC).

## Зависимости
`pip install bleak` (+ `Pillow` для png/jpg).
Рация включена + Bluetooth programming mode.
