**Custom firmware** based on v1.0.3.8, utilizing the h9toolbox by melidosian/h9toolbox.       
Key features:
- Added password-based radio locking (stack: TD-H9-V1.0.38DKXCE.fw + menu.h9mod + passlock.h9mod)
- Added the ability to change the boot screen via a script (stack: td9_logo.exe)
- Added a boot screen viewer module (stack: bootscreen.h9mod)
- Added the ability to upload images via a script and view them on the radio (stack: td9_kpi.exe + dkxcepic.h9mod)
- Added the ability to load applications via a script (stack: TD-H9-V1.0.38DKXCE.fw + td9_apps.exe)
- Added the ability to upload/download APRS settings (stack: td9_aprs.exe)
- Added a "brick" recovery tool for the radio via HID (stack: h9_ui_flash.exe)
- Added then 'TRACKER' GPS-tracker-navigator  (stack: **tracking.h9mod**)
