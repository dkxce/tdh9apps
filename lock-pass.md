# TD-H9 RADIO LOCK / Блокировка рации паролем

Владельческая функция безопасности рации (для владельца, не обход защиты).

## Хранение пароля

| Вещь | Значение |
|---|---|
| Адрес | ресурсная flash **`0x716FF8`**, 8 байт |
| Где | область перед картинками (`0x717000`); последний сектор font (`0x716000`) |
| Запаролена | все 8 байт = цифры `0-9` или пробел `0x20` (пробелы добивают хвост, минимум 1 цифра) |
| Не запаролена | хотя бы один байт не цифра и не пробел (мод пишет `0xFF`, стёртая ячейка) |

Формат записи 8 байт:
- `[0..len)` — цифры пароля (1..8),
- `[len..8)` — пробелы `0x20` (заполнение короче 8).
- Сброс (не запаролена): все байты `0xFF`.

Условие «запаролена ли»: `pass_locked` = все байты ∈ {`0-9`, `0x20`} **и** есть хотя бы одна цифра.

## Флоу

Общий флаг `skip_check` живёт в RAM `0x2B8DF` (свободный байт, конец satshare-зоны):
`0` — свежий/не задан (при включении питания; на некоторых прошивках мусор `0xFF`),
`1` — разблокировано этой сессией (пароля нет, либо пароль принят),
`2` — залочено: пароль есть, надо проверять.

```
<RADIO LOCK FLOW>

skip_check = 0 # включение питания (0x2B8DF)
<stub>
  ├─ (skip_check == 0 || skip_check == 0xFF) -> # первый проход
  │   ├── Читаем 0x716FF8 - 8 байт
  │   ├── (Пароль отсутствует) -> 
  │   │   └─► skip_check = 1 # все ок
  │   └─► (Пароль присутствует) -> 
  │       └─► skip_check = 2 # надо проверить
  │
  ├─ (Удержан back или skip_check > 1) -> menu app
  │ <menu>
  │   ├── (skip_check == 2) ->
  │   │   ├── (Модуля passcode нет) ->
  │   │   │   ├── skip_check = 1
  │   │   │   └─► Выход из меню, возврат к стоку  
  │   │   └─► (Модуль passcode есть) -> passcode app
  │   │   <passcode>
  │   │       ├─ (skip_check == 2) -> 
  │   │       │   ├─ Читаем 0x716FF8 - 8 байт
  │   │       │   ├─ (Пароль отсутствует) -> 
  │   │       │   │   ├─ skip_check = 1 # все ок
  │   │       │   │   └─► Выход из меню, возврат к стоку  
  │   │       │   └─► (Пароль присутствует) ->
  │   │       │       ├─ ввод и проверка пароля - сверяем  ◀────────┐
  │   │       │       ├─ пароли совпадают ->                        │
  │   │       │       │   ├─ skip_check = 1                         │
  │   │       │       │   └─► Выход из меню, возврат к стоку        │  
  │   │       │       └─► пароли различны ->                        │
  │   │       │           └─► Вернуться к вводу и проверке пароля ──┘
  │   │       └─► (skip_check != 2) -> 
  │   │           └─► меню блокировки рации
  │   │               ├─ разблокировать рацию (удаление пароля), если есть пароль
  │   │               ├─ заблокировать рацию (просмотр, ввод и запись пароля)
  │   │               ├─ заблокировать сейчас ->
  │   │               │   ├─ skip_check = 2
  │   │               │   └─► Выход из меню, возврат к стоку  
  │   │               └─► Вернуться в меню menu app
  │   └─► (skip_check != 2) ->
  │       └─► Вывод меню модулей
  │           ├── passcode
  │           │    └──► passcode: flow аналогичный вышеприведенному
  │           ├──► другой модуль
  │           ├──► ...
  │           └──► другой модуль
  └─► loop() 
```

## Реализация

| Компонент | Файл | Статус |
|---|---|---|
| Стуб: выставление `skip_check` по `0x716FF8` + вход в меню по Back или `skip_check>1` | патч `custom_firmware/stub/stub.s` | работает |
| Меню: при `skip_check==2` ищет и запускает `PASSLOCK`, иначе fail-open; при `skip_check!=2` — обычный список модулей | `custom_firmware/menu/menu.c` (база `menu_base.c`) | работает |
| Модуль `PASSLOCK`: boot-ветка (`skip_check==2` → ввод+проверка), обычная ветка (`menu_loop`: LOCK/UNLOCK/LOCK NOW) | `myapps/passlock/src/passlock.c` | работает |
| Чтение через `api->read` | `0x716FF8`, 8 байт | подтверждено |
| Запись пароля через S2 (erase+program, обход защиты font) | `td9_kpi.py pass / passclear / passread` | работает |

Примечания по реализации:
- stub читает `0x716FF8` через `ml_read` (стоковый `0x01E4FF22`) только на первом проходе; далее по `skip_check` — авто-вход в меню (если 2) или обычный hold-Back.
- `ml_main` в stub сделан возвращаемым (keep frame) — меню и PASSCODE не роняют/не ребутят рацию при выходе.
- Меню при `skip_check==2` не рисует список, а сразу возвращает индекс `PASSLOCK` (или fail-open `skip_check=1` при его отсутствии).
- `PASSLOCK` при `skip_check==2` показываeт только экран ввода пароля, до совпадения (неверный пароль → снова ввод).
- Пункт «Locked: меню блокировки» (LOCK/UNLOCK/LOCK NOW) доступен при обычном входе в PASSCODE из списка модулей (`skip_check != 2`).

## Инструмент (BLE)

```
python td9_kpi.py pass       --password 123456   # установить пароль
python td9_kpi.py passclear                       # сбросить (0xFF)
python td9_kpi.py passread                        # прочитать 8 байт
```
Пишет в `0x716FF8` через S2: программирует 32-байтный блок, не трогая font-сектор (запись только в стёртые `0xFF` ячейки).
